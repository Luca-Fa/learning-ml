# ESA Machine Learning Journey

This repository documents my progression in Machine Learning, from scientific Python fundamentals to Deep Learning applications.

The goal of this project is to build a strong foundation in data science, machine learning, and software development while preparing for research-oriented and space-related engineering opportunities.

## Repository Structure

### Lessons

- `sci-py.py`
  - Scientific Python fundamentals
  - NumPy
  - Pandas
  - Matplotlib
  - Data manipulation and analysis

- `first-ml.py`
  - Machine Learning fundamentals
  - Data preprocessing
  - Model training
  - Model evaluation with Scikit-Learn

- `learning-dl.py`
  - Deep Learning introduction
  - Neural Networks
  - TensorFlow / Keras
  - Convolutional Neural Networks (CNNs)

### Datasets

Contains datasets used throughout the lessons and projects.

### Notebooks

Jupyter notebooks used for experimentation, visualization, and exploration.

### Projects

Practical projects applying concepts learned in the lessons.
